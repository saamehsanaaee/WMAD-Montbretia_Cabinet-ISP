# Contents of ```notebooks``` folder:
- `WMAD_GNN_LSTM_original_ver.ipynb` → The original version of our GNN-LSTM.
- `WMAD_model_alt_version.ipynb` → Working version of our WMAD model. *This is the working version of WMAD!*
- `WMD_preliminary_model.ipynb` → Final version of the preliminary Working Memory Demand model.
- `environment.yml` → `.yml` file specifying the Python version and package dependencies (use with `conda`).
- `prediction_vectors.zip` → Zipped version of the prediction `.npy` files generated by `WMAD_model_alt_version.pth`.
- `requirements.txt` → `.txt` file specifying Python packages (install using `pip install -r requirements.txt`).
- `surface_visualization.ipynb` → Work-in-progress notebook for our visualizations.
